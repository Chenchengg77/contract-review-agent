📖 关于这个项目

这是一个合同智能审查 Agent：解析合同 → LLM 抽取 13 类条款 → 规则 + 语义双层风险判定 → 人工确认 → 生成审查报告。

技术栈：Python / FastAPI / LangGraph / DeepSeek API / 原生 HTML·CSS·JS + Tailwind。

评估集 31 份合同 / 403 条，抽取准确率 95.53%，单份成本约 1 分钱。
