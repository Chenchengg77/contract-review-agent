# 5 分钟演示脚本

> 目标：让面试官在 5 分钟内看到「**这是个能用的产品**」而不是「一个能跑的脚本」。

---

## 0. 演示前 10 分钟准备

| 检查 | 做法 |
|---|---|
| 服务已启动 | 本地 `uvicorn api:app --port 8000`；线上先打开一次唤醒（免费版冷启动约 50s） |
| 账号就绪 | `admin / admin123`（管理端）、`demo / demo123456`（用户端） |
| 数据就绪 | 个人中心至少有几条审查记录，看板不为空 |
| 标签页预开 | 首页、审查页、聊天页各开一个，避免现场等加载 |
| 兜底 | 截图/录屏存本地，网络挂了直接放 |

---

## 1. 首页（40 秒）

**打开**：`/`（或线上地址）

**说**：
> 这是一个合同智能审查 Agent。上传合同后自动识别 13 类核心条款、判定风险等级、给出修订建议。
> 首页这里放了两个可验证的东西：一个是**和直接用 AI 聊天的差异**，一个是**评测数据**——35 份合同 403 条金标，判定准确率 91.07%。

**滚到对比区（15 秒）**：
> 比如问「今天天气怎么样」，没有护栏时模型会照常调用、消耗 token；加了前置护栏后直接拒答，成本为 0。

---

## 2. 合同审查（90 秒）

**操作**：`/review` → 选一份**填充示例**（`示例_填写版_家具买卖合同_冲突.docx`）→ 点开始审查

**说**（边等边说）：
> 审查分四步：解析 → 抽取 → 判定 → 修订。单份约 16 秒、成本约 1 分钱。
> 抽取时要求证据必须能在原文里搜到，防模型编造；判定是规则层 + 语义层两层。

**结果出来后（30 秒）**：
> - 这里是 13 类条款，每条有风险等级和结论（合规/偏离/缺失/冲突）
> - 点条款号能看到**原文**，可核对
> - 偏离和冲突的条款给了**修订建议**，可以一键复制
> - 注意这里判了「冲突」——违约金超过合同总额 20%，规则层识别出来的

---

## 3. AI 对话（60 秒）

**操作**：`/chat` → 问「这份合同有哪些风险条款？」

**说**：
> 它不是通用聊天，是锚定在当前合同上的。回答会带条款引用，点引用能看原文。
> 如果问合同里没有的东西，它会说「没找到」而不是编——因为检索不到就不调模型。

**追问（可选）**：问一句「今天天气怎么样」
> 这个问题会被前置护栏拦掉，直接拒答，不花 token。

---

## 4. 个人中心（40 秒）

**操作**：右上角头像 → 个人中心

**说**：
> 概览里是个人审查数据：审查次数、风险分布、按合同类型的风险画像——比如「买卖合同的保密条款最容易出问题」，这是他自己审出来的结论。
> 我的审查里可以筛选、查看报告详情。

---

## 5. 管理端（70 秒）

**操作**：退出 → `admin / admin123` 登录（自动进管理端）

**说**：
> 管理端是独立的一套：看板、用户管理、审查记录、系统运维。

**看板（25 秒）**：
> 近 7 天趋势、合同类型分布、风险构成。图表用 ECharts，按需引入，只在管理端加载。

**系统运维（25 秒）**：
> 健康检查分了层：左边是核心状态（数据库/AI/文件服务），右边是 5 个运维指标。
> 下面是运行时配置——护栏开关、检索阈值、审查超时，改完立即生效，不用重启。

**失败记录（20 秒，可选）**：
> 失败会记录错误类型、可一键重试。点「模拟故障」会注入演示数据，用来演示告警链路（真实失败记录不会被清理）。

---

## 常见追问与准备答案

| 问 | 答 |
|---|---|
| 准确率怎么算的？ | 31 份合同 403 条人工金标，脚本可复跑；verdict 比抽取低是因为判定标准更严 |
| 会幻觉吗？ | 抽取要求原文可搜；问答检索不到直接拒答；护栏拦越界问题 |
| 能替代律师吗？ | 不能。定位是「初审辅助」，结论都要人工确认，界面上也有免责声明 |
| 改了代码怎么保证不坏？ | 37 个 pytest + CI；改 bug 有前后评测对比（85.36% → 91.07%） |
| 为什么是 SQLite / 同步请求？ | 演示场景够用；上生产换 PG + 任务队列（已在 README 已知局限里写明） |

## 出问题的兜底

| 情况 | 处理 |
|---|---|
| 大模型超时 | 切到已审查好的合同，直接讲报告 |
| 线上冷启动慢 | 本地跑（提前启动好） |
| 网络断 | 放录屏，按脚本讲 |
| 数据被清空 | 现场审 1 份，等 16 秒 |
